## 🚀 Key Features

- **Swiss Architectural Design System**: Editorial typography (`Manrope`), precision hairline grids, and geometric brand accents.
- **Adaptive Liquid Glass Architecture**: Frosted glass panels with real-time specular highlights and multi-layer depth.
- **Full Light & Dark Mode**: Seamless toggle across all routes with `localStorage` state persistence and brand mark contrast protection.
- **Continuous Background Telemetry**: Cyber-telemetry particle animation in dark mode and technical drafting blueprint schematic in light mode.
- **Lenis Smooth Scrolling**: Inertia-driven physics for desktop wheel scrolling and optimized touch physics for mobile viewports.
- **Multi-Page Enterprise Routing**: Dedicated sections for Home, About, Services, Sectors, Partner Ecosystem, Process, and Dispatch Inquiries.
- **Network & Corridor Ecosystem**: Vector partner emblems for `TOWERGRID`, `APEX HAULAGE`, `INFRACONNECT`, and `NEXUS CORRIDOR`.

## 🛠️ Tech Stack

- **Core**: React 19, Vite
- **Routing**: React Router DOM v7
- **Smooth Scrolling**: Lenis v1.3
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Tailored Design Tokens & HSL Curated Palettes)
- **Deployment & CI/CD**: Vercel Git Integration

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/DataBuks11/vr-multiventures.git

# Navigate to directory
cd vr-multiventures

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
